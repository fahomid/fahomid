## About me

I am a backend and full-stack software engineer with over a decade of experience building production web, mobile, and SaaS products.

From 2014 to September 2025, I worked independently with international clients and delivered more than 100 projects. Clients often came to me with a rough idea, an unfinished product, or a technical problem that first needed to be understood. I turned those requirements into working systems and handled the process from planning and architecture through development, deployment, and long-term support.

Freelancing rarely meant solving the same problem twice. I regularly moved between unfamiliar codebases, technologies, business requirements, and production environments. That experience taught me how to learn quickly, debug carefully, make practical decisions, and take responsibility for the final result.

Today, I build independent products through **77beats** and am open to joining a collaborative engineering team where I can apply that experience at a larger scale.

## How I build

I spend most of my time getting the core of a system right before expanding it.

When a problem is large, I divide it into smaller, clearly defined parts and solve each one carefully. This keeps the architecture understandable, makes failures easier to isolate, and allows components to be tested and improved independently.

I value practical architecture, clear responsibilities, measurable performance, maintainable code, and systems that can grow without becoming unnecessarily complicated.

### [efficient-token](https://github.com/fahomid/Efficient-Token)

A local-first TypeScript MCP server that helps coding agents retrieve only the code context needed for a task instead of reading entire files.

It includes tree-sitter-based symbol extraction, 47 focused tools, workspace-confined file access, atomic operations, syntax-guarded edits, automated tests, CI, security documentation, and verifiable build provenance.
